# 단대부고 단어 챌린지 · DAY 38–40

능률VOCA 수능 고난도 DAY 38~40 단어로 연습하는 웹 게임입니다. 파일 하나(`index.html`)에 단어 데이터·이미지·효과음이 모두 들어 있어 서버 없이 바로 열립니다.

- 단어 짝맞추기 (Word Matching) — 16장 카드, 8쌍, 시간 기록
- 의미 선택하기 (Choose the Meaning) — 20문제, 오답 +3초
- 예문 철자 맞추기 (Spell It!) — 알파벳 타일로 단어 완성, 난이도 3단계, 점수·콤보·오답 노트

## GitHub Pages로 배포하기

1. 이 저장소를 GitHub에 올립니다 (`index.html`, `README.md`).
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 선택하고 저장합니다.
3. 1~2분 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/` 주소로 접속됩니다.
4. 이 주소를 QR 코드로 만들어 학생들에게 배포하세요. 로그인 없이 태블릿·휴대폰 브라우저에서 바로 실행됩니다.

## 참고

- 글꼴(Pretendard)은 CDN에서 불러오며, 인터넷이 막힌 환경에서는 기기 기본 글꼴로 표시됩니다.
- 단어 발음은 브라우저 내장 음성(Web Speech API, en-US)을 사용합니다.
- 짝맞추기·의미 선택하기의 **세트 번호**를 같은 값으로 입력하면 반 전체가 같은 문제로 겨룰 수 있습니다.

## 홈 화면에 앱처럼 추가하기

`manifest.json`과 `icon-*.png` 덕분에 홈 화면에 추가하면 곰돌이 VOCA 아이콘으로 표시됩니다.

- **아이패드·아이폰(Safari)**: 공유 버튼(□↑) → **홈 화면에 추가**
- **갤럭시(삼성 인터넷·Chrome)**: 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**
